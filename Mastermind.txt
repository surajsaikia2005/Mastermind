Question 1 :  To create a Git repository, implement a professional branching strategy, merge branches, 
resolve merge conflicts, and upload the project to GitHub.

Solution:
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

create project> create folder> enter folder> git init
create README => echo "#DevOps Lab" > README.md
git status, add, commit
git branch, git branch development, git checkout development
create index.html, add, commit
git checkout -b feature/login {add login section}, add, commit
git checkout development, git merge feature/login
git checkout main, git merge development

git checkout development, {Change code "Hello development"}, add, commit
git checkout main, {Change same line to "Hello main"}, add, commit
git merge development

change line to "Hello main and development", add, commit

create repo, push
